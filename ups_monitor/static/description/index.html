UPS Monitor

A Raspberry Pi reads an APC UPS through NUT and pushes the data to Odoo. Odoo stores the time series, detects mains outages and shows charts, outage history and events.

Features

  • Dashboard: live tiles, a mains-voltage chart with a min-max band per minute (a dip of a few seconds stays visible), battery charge, load, runtime, a voltage histogram and red bands over the periods on battery. Periods from 1 hour to the whole history, with back and forward arrows.
  • Statistics: mains availability, outage count and duration, time since the last outage, voltage average, lowest, highest and spread, minutes outside the thresholds, average and peak load in % and watts, energy in kWh, lowest battery charge and the last self-test.
  • UPS cards: status, battery charge, load, mains voltage and agent state at a glance.
  • Charts: plain Odoo graph, pivot and list views of the samples for ad-hoc grouping.
  • Mains outages: start, end, duration, lowest battery charge and low-battery flag for each outage, plus a monthly bar graph.
  • Events: status changes and UPS communication losses reported by the collector.
  • Alerts: chatter messages (emailed to followers) when mains fails, returns, or the Raspberry agent goes silent.

Resilient by design

When the mains fails the agent sends the change within a couple of seconds and then every 10 seconds while the UPS runs on battery.

The Raspberry keeps every sample in SQLite and advances its cursors only after Odoo confirms. If Odoo is down the agent backs off (60 s up to 15 min, with jitter) and sends the backlog in batches once Odoo answers. Resending a batch never creates duplicates.

Setup

  1. Install the module. It creates the shared token in the system parameter ups_monitor.token.
  2. Copy the agent/ folder to the Raspberry and run install.sh.
  3. Enter the Odoo URL and the token in /etc/upsmon/odoo-push.env.
  4. Add the users who should receive alerts as followers of the UPS.
