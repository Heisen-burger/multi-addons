Telegram Bot

Generic Telegram Bot API layer for Odoo: any number of bots, one webhook per bot, chat registry, access code, command and callback routing, HTML messages and file uploads. Other modules add a bot kind by inheriting two models.

Features

  • Bots: one record per bot with token, kind, webhook secret, access code and welcome text; webhook registration from the form.
  • Webhook per bot, protected by the Telegram secret token header, always answering 200.
  • Chat registry: one record per bot and chat, archived on /stop or when the user blocks the bot, revived by any later message.
  • Access code: optional per bot; new chats must send /start followed by the code, or open the t.me link that carries it.
  • Routing: /command to _cmd_<command>, inline button data to _cb_<key>, free text and shared locations to dedicated hooks, one handler model per bot kind.
  • Client: one method per Bot API call, HTML messages with inline or reply keyboards, audio, video, voice, photo and document uploads.
  • No dependency beyond the requests library shipped with Odoo.

Configuration

  1. Create the bot with @BotFather and copy the token.
  2. Settings > Technical > Telegram > Bots: new record, paste the token, pick the kind.
  3. Press Register Webhook.
