Telegram Media Download Bot

Send a link to the bot, get the file back. One provider per site, Suno included. Providers decide what they return: an MP3 today, a video or a document tomorrow.

Features

  • Links in, files out: audio, video, voice, photo or document, sent with the matching Telegram method.
  • Suno: song and short links, title, artist, duration, cover art and tags from the public clip API, MP3 with ID3 tags.
  • Provider registry: a new site is one file with a regex and a fetch method.
  • Download log: every link with provider, title, size, state and error.
  • Access code and everything else from the Telegram Bot base module.

Requirements

ffmpeg installed on the server.
