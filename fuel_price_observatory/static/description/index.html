Fuel Price Observatory

Italian fuel prices from the MIMIT observatory inside Odoo: every station, every fuel, a history of each price change, and chatter alerts for the price lists you follow.

Features

  • Price lists: one record per station, fuel and service mode with current price, historical minimum and maximum, each with its date.
  • Price history: one row per price change with the previous price.
  • Stations: brand, manager, type, address, city, province, coordinates.
  • Alerts: follow a price list from its chatter. Every change posts a message; followers get it by email or in their inbox according to their notification preference.
  • Scheduled sync: prices every 30 minutes from the observatory API, station registry once a day from the MIMIT CSV. Manual triggers under Fuel Prices > Configuration.

Data sources

Source Cadence Content
Observatory app API every 30 minutes all stations with current fuel prices
Registry CSV daily manager, station type, street, city, province

How the sync works

  1. Download the full dump.
  2. Create missing stations and price lists.
  3. Compare each communication id with the stored one: same id, nothing; new id and same price, update the date; new id and new price, update the list and append a history row.
  4. Post a chatter message on every changed price list that has followers.

Access rights

Internal users read everything and can follow price lists. Administrators manage records and run the manual sync.
